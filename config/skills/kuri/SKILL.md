# Kuri

Browser automation & web crawling for AI agents. Single Zig binary, zero Node.js.

> **Important:** ExHub already manages a kuri daemon (`Exhub.KuriDaemon`). **Always reuse the existing instance** instead of starting a new one. Do not run `kuri` or `kuri-agent` commands directly unless the daemon is confirmed unavailable.

> **kuri 0.6.0 suite:** `kuri` (HTTP/CDP server), `kuri-fetch` (no-Chrome fetch), `kuri-browse` (terminal browser), `kuri-agent` (scriptable CLI), `kuri-mobile` (`mcp` stdio server for iOS/Android), `kuri-gateway`. The `kuri` binary is on PATH (install dir may be `~/.cargo/bin` or `~/.local/bin`); `kuri token` prints the API token.

## Reusing the ExHub-Managed Instance

### Check Status

```bash
# (generated by ExHub's KuriDaemon, shared with standalone kuri)
cat ~/.kuri/api.token
```

### HTTP API Base URL

```
Base URL:  http://127.0.0.1:18080
Auth:      Bearer <token from ExHub's KuriDaemon>
```

### Verify Before Use

```bash
# Check if the ExHub-managed instance is healthy
curl -s http://127.0.0.1:18080/health
# → {"ok":true,"tabs":1,"version":"0.6.0","name":"kuri"}

# If healthy, reuse it. Do NOT start a new instance.
```

## HTTP API (Primary Interface)

Use the ExHub-managed HTTP API directly. All requests need the `Authorization: Bearer <token>` header.

### Session Management

```bash
TOKEN=$(cat ~/.kuri/api.token 2>/dev/null || echo "")

# Create a new tab
curl -s -H "Authorization: Bearer $TOKEN" \
  http://127.0.0.1:18080/tab/new
# → {"tab_id":"...","url":"about:blank","title":""}

# List tabs
curl -s -H "Authorization: Bearer $TOKEN" \
  http://127.0.0.1:18080/tabs
# → [{"id":"...","url":"...","title":"..."}]

# Navigate a tab
curl -s -H "Authorization: Bearer $TOKEN" \
  -X POST -H "Content-Type: application/json" \
  -d '{"url":"https://example.com"}' \
  http://127.0.0.1:18080/tabs/<tab_id>/navigate

# Close a tab
curl -s -H "Authorization: Bearer $TOKEN" \
  -X DELETE \
  http://127.0.0.1:18080/tabs/<tab_id>
```

### Page Interaction

```bash
# Get accessibility snapshot (compact, ~750 tokens)
curl -s -H "Authorization: Bearer $TOKEN" \
  "http://127.0.0.1:18080/tabs/<tab_id>/snapshot?filter=interactive&format=compact"

# Get full snapshot (~2,124 tokens)
curl -s -H "Authorization: Bearer $TOKEN" \
  http://127.0.0.1:18080/tabs/<tab_id>/snapshot

# Click an element
curl -s -H "Authorization: Bearer $TOKEN" \
  -X POST -H "Content-Type: application/json" \
  -d '{"action":"click","ref":"e0"}' \
  http://127.0.0.1:18080/tabs/<tab_id>/action

# Type text
curl -s -H "Authorization: Bearer $TOKEN" \
  -X POST -H "Content-Type: application/json" \
  -d '{"action":"type","ref":"e1","text":"hello"}' \
  http://127.0.0.1:18080/tabs/<tab_id>/action

# Screenshot
curl -s -H "Authorization: Bearer $TOKEN" \
  http://127.0.0.1:18080/tabs/<tab_id>/screenshot > screenshot.png
```

### Security Testing

```bash
# Get cookies
curl -s -H "Authorization: Bearer $TOKEN" \
  http://127.0.0.1:18080/tabs/<tab_id>/cookies

# Get security headers
curl -s -H "Authorization: Bearer $TOKEN" \
  http://127.0.0.1:18080/tabs/<tab_id>/headers

# Run security audit
curl -s -H "Authorization: Bearer $TOKEN" \
  http://127.0.0.1:18080/tabs/<tab_id>/audit
```

## Token Efficiency

| Mode | Tokens | Best For |
|------|--------|----------|
| `/page/state` | ~48 | Lightweight check |
| `snapshot?filter=interactive&format=compact` | ~750 | Agent loops |
| `snapshot` (full) | ~2,124 | Full page understanding |
| `screenshot` | ~100,000 | Visual verification |

## Agent-Friendly Loop

```bash
TOKEN=$(cat ~/.kuri/api.token 2>/dev/null || echo "")
TAB_ID=$(curl -s -H "Authorization: Bearer $TOKEN" http://127.0.0.1:18080/tab/new | jq -r '.tab_id')

# Navigate
curl -s -H "Authorization: Bearer $TOKEN" \
  -X POST -H "Content-Type: application/json" \
  -d '{"url":"https://example.com"}' \
  http://127.0.0.1:18080/tabs/$TAB_ID/navigate

# Observe (compact snapshot)
curl -s -H "Authorization: Bearer $TOKEN" \
  "http://127.0.0.1:18080/tabs/$TAB_ID/snapshot?filter=interactive&format=compact"

# Act
curl -s -H "Authorization: Bearer $TOKEN" \
  -X POST -H "Content-Type: application/json" \
  -d '{"action":"click","ref":"e0"}' \
  http://127.0.0.1:18080/tabs/$TAB_ID/action

# Verify
curl -s -H "Authorization: Bearer $TOKEN" \
  "http://127.0.0.1:18080/tabs/$TAB_ID/snapshot?filter=interactive&format=compact"
```

## Fallback: When ExHub Daemon Is Unavailable

Only use these commands if `Exhub.KuriDaemon.status()` returns `:stopped`, `:disabled`, or `:unhealthy`.

### Start a Standalone Instance

```bash
# Start kuri on a different port to avoid conflict with ExHub
PORT=18081 kuri

# Or use a different Chrome instance
PORT=18081 CDP_URL=http://127.0.0.1:9222 kuri
```

### kuri-agent CLI (Standalone Mode)

```bash
# List Chrome tabs
kuri-agent tabs [--port N]

# Attach to a tab
kuri-agent use ws://127.0.0.1:9222/devtools/page/ABC123

# Navigate + interact
kuri-agent go https://example.com
kuri-agent snap --interactive
kuri-agent click e0
kuri-agent shot
```

## Configuration

| Env Var | Default | Description |
|---------|---------|-------------|
| `HOST` | 127.0.0.1 | Server bind address |
| `PORT` | 8080 | Server port (ExHub uses 18080) |
| `CDP_URL` | (none) | Connect to existing Chrome |
| `KURI_API_TOKEN` | (none) | Auth secret for API |
| `KURI_PROXY` | (none) | SOCKS5/HTTP proxy |

  -X POST -H "Content-Type: application/json" \

TOKEN=$(cat ~/.kuri/api.token 2>/dev/null || echo "")
